# Painter essays

Create one Markdown file per painter using the database slug as the filename.

```md
---
title: Painter display name
artist_slug: painter-slug
status: draft
sources:
  - https://museum.example/artist/painter-slug
---

Write the sourced essay here.
```

Use `draft`, `review`, or `published`. Do not copy museum prose. Keep factual
claims traceable to the listed sources and move an essay to `published` only
after a human editorial pass.
