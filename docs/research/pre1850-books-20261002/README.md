# Pre-1850 book expansion — 2 October 2026

Added 23 original works and seven creator records to both the local catalogue and production. Eighteen of the additions are by women. All additions retain review status and are visible through the existing public research preview at https://artlines.org. No earlier records were republished.

The collection now has 10,068 books, including 2,171 dated before 1850. Highlights contain 255 books and 201 authors, all returned by the existing bounded highlight views. The production app reads these catalogue changes dynamically; no application build or runtime configuration change was required.

## Selection and source review

Research began with 52 targeted titles and returned 44 matched Wikipedia pages. Duplicate source identities, disambiguation pages, an unrelated modern novel, a film adaptation and unresolved candidates were excluded. Work identity was checked independently of edition, author and translation identity. Two existing books titled The Wanderer are the Old English poem and Fritz Leiber’s 1964 novel; neither duplicates Frances Burney’s 1814 novel added here.

The Old Manor House retains the documented composition range August 1792–January 1793, expressed as 1792–1793. Oedipus Aegyptiacus retains its three-volume publication sequence of 1652–1654. Tableau économique uses the explicitly documented 1758 manuscript/work date; the conflicting Wikidata publication value 1759 remains in the retained source evidence. First performance, publication and composition are distinguished in the individual date-basis fields. No exact composition date was inferred from a later edition.

English was confirmed for works whose Wikidata language field was missing using the original text, publisher language metadata, a historical translation explicitly identified as translated from English, or the matched Wikipedia English-language classification. All other original languages were checked against the matched work identity. No country was inferred from an author’s nationality.

Each book includes an original short description and an attributed Wikipedia introduction linked to its exact revision. The seven newly added creators also have sourced introductory biographies. Existing creator records were preserved.
