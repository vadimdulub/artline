# Current SMK image recovery — 6 October 2026

**Two public-domain reproductions are saved locally and attached to existing artworks:** Vilhelm Lundstrøm's *Opstilling* (1937, KMS9205) and Jens Vige's *Maleren Niels Bjerre* (1896, KKS14704). Both retain their existing titles, dates, artist records and identifiers, holding assertions and review status. File checks, database links and complete stored source evidence passed verification.

The [current metadata audit](../local-smk-current-metadata-20261006/README.md) identified these two new leads. Each full native object record was then refreshed individually. Lundstrøm's preferred image decoded to a nearly black rectangle with no usable artwork depiction. It was rejected before any database attachment; its public derivative was removed after checksum verification. The validator permits only this individually reviewed alternate and continues to reject an unlisted image or omitted source proof.

The pencil drawing is photographed in colour on toned paper; it is not labelled as a monochrome photograph of a colour painting.
