# Commons portrait-source review — 7 October 2026

Four existing Russian Museum portrait gaps were researched through exact native pages and four current Commons file revisions. **No images were downloaded or attached.** All four catalogue records and their creator authorities were rechecked unchanged in the local database. Commons source labels are preserved without treating them as completed photograph-origin or physical-version approvals.

**Портрет Владимира Герарда** — The Commons file credits the exact Virtual Russian Museum Gerard reproduction. The current originating portal terms limit its content to personal noncommercial and educational uses. Preserve the Commons Public domain assertion but hold this museum-origin photograph under the general image-use policy. WikiArt approval is not an extension to this museum source. [Commons file](https://commons.wikimedia.org/wiki/File:%D0%93%D0%B5%D1%80%D0%B0%D1%80%D0%B4_%D0%92%D0%BB%D0%B0%D0%B4%D0%B8%D0%BC%D0%B8%D1%80_%D0%9D%D0%B8%D0%BA%D0%BE%D0%BB%D0%B0%D0%B5%D0%B2%D0%B8%D1%87.jpg).

**Портрет Б. Н. Чичерина** — The Commons file describes a 1903 Chicherin portrait in the Tambov gallery and is a vertical image. The exact native inventory Р-13434 is a 1902 horizontal charcoal/coloured-pencil drawing, 52.3 by 67.5 cm. Different date, medium, collection and format identify another physical version; reject before image download. [Commons file](https://commons.wikimedia.org/wiki/File:Boris_Chicherin_by_V.Serov.jpg).

**Портрет Е. П. Кончаловской** — Commons names Elena Konchalovskaya, 1891, Russian Museum, with a Public domain assertion, but credits a Rulex portrait page rather than an identified independent photograph or verified originating permission. The file is substantially more vertical than native Ж-6650, 62 by 58.5 cm, so framing/version also requires comparison. Preserve the lead; no exact-version or photograph-clearance approval is made. [Commons file](https://commons.wikimedia.org/wiki/File:Elena_Konchalovskaya_by_V._Serov_(1891%2C_GRM).jpg).

**Портрет композитора Н.А. Римского-Корсакова** — Commons describes Repin’s 1893 Rimsky-Korsakov portrait with matching 125 by 89.5 cm dimensions and asserts Public domain/PD-Art. It credits a historic Lappeenranta city image URL. The metadata does not establish the photograph’s original supplier or any separate originating permission; retain this promising exact-subject lead for provenance follow-up. No image download or attachment approval is claimed. [Commons file](https://commons.wikimedia.org/wiki/File:Rimsky-Korsakov_by_Repin.jpg).

The [originating portal terms](https://virtualrm.spb.ru/ru/node/13311) are captured with the exact Gerard source page. The other two originating URLs were checked without downloading image bodies. The previous fuzzy WikiArt suggestions name different sitters; none was accepted as an identity match. The public application asset folder was not created by this review.
