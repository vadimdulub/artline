# Selected Wien Museum follow-up — 6 October 2026

Reviewed 17 existing missing-image artworks and attached eight native museum photographs. Each selected photograph explicitly permits CC BY 4.0 reuse and credits Birgit und Peter Kainz, Wien Museum. The additions are works by Ranftl, Klimt, Waldmüller, Kurzweil, Romako, Füger, Amerling and Makart.

Native titles, inventories, sole artist names, dates and dimensions were compared with existing records and their authority data. Individual identity decisions are retained in each selected-image record. Missing inventory fields remain missing. Native uncertainty, including Klimt's circa-1894 qualifier and unknown sitter, remains evidence rather than a catalogue edit. Romako's documented restitution and reacquisition history was preserved in the source capture; no provenance or holding fields were rewritten.

All eight full compositions were visually reviewed. Original frames and external colour targets remain where present; no image was cropped. All derivatives are below 100,000 bytes. Checks of the database associations, file and archived-source hashes, exact licence and photographer credits passed. Four offline controls rejected changed rights, wrong object photos, conflicting dates and missing photographer credit. The existing Next.js server timed out during the final local HTTP check; delivery verification remains incomplete.

Nine records remain unattached. These include two copyright reviews, three conflicting-date cases, an authority link to a historical photographic negative, two unresolved native object pages and one candidate requiring further identity/precision reconciliation. No existing metadata, creator links, identifiers or review status changed. No fixtures, catalogue records or production changes were made.
