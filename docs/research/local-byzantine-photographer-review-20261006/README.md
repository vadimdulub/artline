# Byzantine independent-photographer lead — 6 October 2026

An independent Commons photograph identifies the exact existing Athens inventory **ΒΧΜ 00995**, *Double-sided icon with the Crucifixion and the Virgin Hodegetria*. Both the current native museum page and Commons wikitext were captured, with revisions and hashes. The local record is missing an image and intentionally retains unknown creation dates. It was left unchanged; no image was downloaded or attached.

The file is an own photograph by Giovanni Dall'Orto, taken in 2009. Its wikitext explicitly separates the old artwork's public-domain status from the raw photograph's attribution-only permission. That permission allows commercial use, redistribution and derivatives when the copyright holder is credited. The API's public-domain summary alone does not preserve this distinction; a later attachment must retain the photographer's credit and the exact permission evidence.

The photograph shows the Crucifixion face. It must not imply that the reverse Hodegetria face is also pictured. The native description distinguishes front layers from the 9th, 10th and 13th centuries and a 16th-century reverse repaint. These descriptions were retained as evidence without assigning a single creation year, replacing the record's unknown dates or changing its review status.

The next step is an individually reviewed image-only attachment that preserves the unresolved catalogue dating and accurately labels the pictured face. The existing automatic eligible-date attachment path was not bypassed in this operation. This record is an additional distinct review, not one of the seven earlier Byzantine candidates.
