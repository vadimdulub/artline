## Source and identity review

- WikiArt is the approved image reference. Actual source rights labels, credits, retrieval receipts, source images and checksums are preserved separately from user approval.
- Known dates after 1970 are excluded. Unknown or conflicting creation dates remain explicit in review. Version, attribution, translation and duplicate questions are recorded; source listings need not represent distinct physical objects.
- Existing images, catalogue metadata and holding assertions are preserved. Personal selections do not assert museum designation or current display.

Duplicate and conflicting source identities were screened before insertion; this campaign did not archive any existing artwork.

Current catalogue totals may include concurrent additions by other operations. This operation’s additions are counted only from its own committed receipts and documented reconciliations.

## Verification

- Fresh production identity validation, a successful Cloud SQL backup, immutable plans, and per-artist application and verification receipts support the results. Image uploads use create-only object generations and public byte verification. Bounded public artist APIs confirm delivered attachments.
- Every selected image receives decoding, dimensions, proportions, byte-budget, checksum and duplicate checks. Visual sampling covers each artist and all flagged identity, low-resolution and placeholder cases. It does not imply manual viewing of every image.
- Backups, originals, review sheets and held derivatives live under Artline Application Support outside Documents. The real local database is unchanged. No commits, application deployment or publication were performed.
