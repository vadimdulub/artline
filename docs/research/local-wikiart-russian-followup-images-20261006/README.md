The [Alexander portrait source](https://www.wikiart.org/en/karl-bryullov/portrait-of-alexander-bruloff) matches [graphite drawing Р-13105](https://rusmuseumvrm.ru/data/collections/drawings/r-13105/index.php), with its characteristic hands on the chair back, neckcloth and inscription. It differs from [Italian-pencil drawing Р-2257](https://rusmuseumvrm.ru/data/collections/drawings/r-2257/index.php). The supplied reproduction omits part of the lower sheet inscription/margin, so its database view label and accessible description explicitly qualify the source frame. No additional crop was made.

The [alternate Autumn image](https://www.wikiart.org/en/boris-kustodiev/autumn-1918-1) exactly matches the native [ЖС-1265 composition](https://rusmuseumvrm.ru/data/collections/painting/19_20/zhs-1265/index.php): figures at far lower left, dense central foliage, pavilion and matching tree branches. This visual evidence resolves the initial metadata hold. WikiArt’s Private Collection label and 80 × 98 cm dimensions remain evidence alongside the museum’s 78 × 98 cm; neither catalogue holding nor dimensions were changed. The other Autumn page depicts a different composition. Similarly, the [oval Self-Portrait](https://www.wikiart.org/en/karl-bryullov/self-portrait-1) matches [Ж-5077](https://rusmuseumvrm.ru/data/collections/painting/17_19/zh-5077/index.php), while the source dimensions 64.1 × 54 cm and native 56.5 × 43 cm are preserved without inventing a reason for the discrepancy.
