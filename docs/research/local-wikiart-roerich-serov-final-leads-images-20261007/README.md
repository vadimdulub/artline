Contrast and saturation differ; the full supplied composition including signature and lower railing is preserved. Editorial same-work confidence exceeds 90%, based on the separately compared native and source photographs and exact object identity. [Source page](https://www.wikiart.org/en/valentin-serov/coronation-of-the-emperor-nicholas-ii-in-the-uspensky-cathedral-1896).
