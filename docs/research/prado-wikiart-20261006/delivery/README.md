# Prado images from WikiArt — 6 October 2026

Added **53 images to existing production Prado artworks**: 47 new media assets and 6 reused, verified WikiArt assets. Prado coverage increased from **183 to 236 of 548 artworks**; **312 still lack a primary image**. All 548 artwork records remain in review.

WikiArt is recorded as the image provider. Each attachment retains its exact WikiArt artwork page, direct image URL, original source rights label, attribution and captured evidence. This follows the [documented user instruction](../../../ARTLINE_IMAGE_USE.md#prado-production-images--6-october-2026). Source labels are recorded as claims, not independent licences.

## Selection and verification

The two research rounds identified 85 metadata-supported matches and 26 candidates. The fresh production audit selected 55 missing-image records with eligible known creation dates; 8 were earlier candidates whose identity was further corroborated. Visual review approved 53. Existing pictures, dates, creators, museum assertions and editorial states were preserved.

The original Bosch Adoration candidate was a landscape detail. It was replaced with the complete triptych from a separate WikiArt page. For Caravaggio, the alternate reproduction on the same page restored the full supplied composition. All new derivatives preserve the chosen source frame, use proportional resizing without cropping, and are at most **99,981 bytes**.

All 53 image attachments, exact source references, rights evidence, decoded files, checksums and public image responses passed verification. All 53 live artwork API responses return the expected image. The other 495 records and their attachments are unchanged. No artworks were created or published; the local database was not changed.
