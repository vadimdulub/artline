# Priority icon research alongside the seven rounds

Added and verified one image for the existing **Archangel Michael**, Athens
object `63`, accession **ΒΧΜ 01353**, artwork UUID
`5e651901-6216-4b9c-afa2-b1e7d6174658`.

The 97,394-byte JPEG is saved locally, uploaded to Google Storage and attached
in both databases. `verification-final.json` reports matching hashes, sizes,
media metadata, rights evidence and exact museum identifier links, with no
errors. The original catalogue fields and creator links match both pre-image
snapshots. The record remains in review with its existing workshop attribution
and 1301–1350 creation interval.

The [independent photograph by Yair-haklai](https://commons.wikimedia.org/wiki/File:Icon_of_Saint_Michael_in_the_Byzantine_and_Christian_Museum_(Athens).jpg)
is explicitly licensed under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).
The saved derivative retains that license, photographer credit, source link,
and a notice of full-frame resize/JPEG compression. The photograph's 2024 date
is distinct from the medieval artwork's creation date. No new artist authority,
accepted holding or display assertion was added.

The [exact object category](https://commons.wikimedia.org/wiki/Category:Icon_of_Saint_Michael_in_the_Byzantine_and_Christian_Museum_(Athens))
names accession ΒΧΜ 01353 and links to the museum's object 63. The selected file
and category link to one another. The file explicitly identifies the Athens
museum, the photographer and an own-work source. Current full HTML snapshots,
retrieval timestamps and SHA-256 are preserved in `metadata.json`; the original
download matched the published SHA-1 `49179ecf55f36a259094262b58437e19e56e456e`.
The derivative was visually checked: frontal winged Michael, sceptre and globe,
with the full panel and its mounting retained.

Four offline rejection checks on copies of the captured evidence verified that
changed accession numbers, license labels, photographer identities and original
checksums are rejected. `guard-tests.json` records those checks; no real-database
test fixtures were used.

Other focused searches covered Athens accession ΒΧΜ 01109 and Kremlin
accessions Ж-1386 and Ж-267. They did not establish another exact reusable match.
The Ж-267 search returned unrelated works in Odesa and Abramtsevo; those were
rejected because an accession string alone does not identify a museum object.
No image from those results was downloaded. Existing museum-photo reuse
restrictions remain unresolved for the other icons.

This is the cross-cutting priority research performed during the first museum
round, recorded separately from its 200 Cleveland drawings. It is not an eighth
bulk research round.
