# Byzantine Commons image review — 6 October 2026

Reviewed seven existing missing-image icons and frescoes in Athens and Thessaloniki, including anonymous makers, a possible Cypriot workshop and creation ranges before 1100. Selection retained their actual labels, types, dates and inventories without requiring a named painter or inventing a biography. No image was downloaded or attached.

For the Athens *Virgin Hodegetria*, Commons names the exact inventory `ΒΧΜ 01109`, and the current native object `64` agrees. Its file is sourced from the museum and labelled PD-old. The museum's current terms limit its content to personal and noncommercial use and require prior written approval for other uses. This museum-origin reproduction is held for independent clearance; the possible Cypriot workshop label remains unchanged. A separate photographer's image could be reviewed independently.

Two Commons *Dexiokratousa XIII* files turned out to identify the Bode-Museum in Berlin. They were rejected for the Thessaloniki *Panagia Dexiokratousa*, inventory `ΒΕΙ 49`. The current Thessaloniki native page was captured to preserve this distinction. The other five bounded searches did not establish an exact file with usable rights; no claim is made that such photographs do not exist.

Search responses, file revisions and museum pages/terms remain under `metadata/`. A final read-only comparison confirmed all seven artwork records were unchanged. No fixtures, catalogue records or images were added; production was not changed.
