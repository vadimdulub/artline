# Rijksmuseum image recovery — 6 October 2026

**Five public-domain reproductions are saved locally and attached to existing artworks.** Forty missing-image paintings with existing Rijksmuseum identifiers were reviewed. The additions are Maes's *Old Woman Spinning* and *Girl at a Window, known as ‘The Daydreamer’*, Weenix's *Portrait of Silvester van Tongeren*, Van Bergen's *Landscape with Herdsman and Cattle*, and Van de Venne's *Winter*.

Current Linked Art records establish each exact object ID, inventory, title or native translation, painting classification, unqualified primary maker ID and creation interval. Approximate-date wording is checked separately from the bounds. Existing artist records and identifiers, catalogue titles and dates, holding assertions and review status remain unchanged. Metadata CC0 is recorded separately from image permission.

The current EDM feed supplies a usable primary image with Public Domain Mark for *Old Woman Spinning*. Four further exact objects omit their image resource from EDM but provide it on the current collection website. Those four native pages explicitly link to the Public Domain Mark, identify the same object and inventory, mark the photograph downloadable and uncropped, and provide dimensions matching the native Rijksmuseum IIIF service. Native Dutch and English titles are matched against the same Linked Art object's names. Ordinary same-site redirects, original page HTML, structured source facts, per-image permission links and service receipts are retained. No catalogue title was translated or overwritten.

All five complete source frames were visually inspected. The largest application JPEG is 97,651 bytes. Files, archived originals, primary-image references, artwork-media associations, complete stored source evidence and credits passed verification. Existing artist authorities and holding assertions were compared separately and remain unchanged. Five positive source checks and seven negative controls passed without database fixtures.

Thirty-five paintings remain unattached: 33 current collection pages have no image resource; one explicitly marks its image not downloadable; and the Boerhaave family portrait's native image service provides only a 71 × 85 pixel grey thumbnail. That thumbnail was inspected at its original size and contains no identifiable artwork depiction. Its 862 source bytes are retained privately; no application derivative or media record was created. The earlier 1,000-pixel request failed with HTTP 400. This is a source-specific image failure, not a change to the artwork's date, identity or rights metadata.

Application JPEGs use `apps/web/public/assets/artworks/imported/local-rijks-native-images-20261006/`. Originals, the rejected grey thumbnail and the approved review sheet are under `/Users/vadimdulub/Library/Application Support/Artline/source-images/local-rijks-native-images-20261006/`. Locked preimages use the matching `Artline/backups/local-rijks-native-images-20261006/` directory. Superseded source selections remain in `history/`.

The native [information and data policy](https://data.rijksmuseum.nl/policy/information-and-data-policy) supplies context; the actual attachment decisions use the exact image permissions above. Production was not changed. Recent HTTP delivery remains unverified following earlier local server timeouts; local-file and database verification passed.
