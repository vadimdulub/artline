# Chicago exact-ID image discovery — 6 October 2026

A read-only comparison of 8,201 existing local missing-image identifier rows (8,174 distinct native object IDs) found 4,056 potential open-image leads. Another 3,948 objects have an image but no explicit open object grant, 167 have no primary image and three IDs are absent from current responses (92999, 155848 and 155851).

This is metadata discovery, not individual source clearance or an attachment count. No catalogue records were created or changed and no image binaries were requested by this audit. Existing exact native identifiers scoped every request. Duplicate local identifier rows remain preserved for individual matching.

The [official API guidance](https://api.artic.edu/docs/) informed the 82 field-limited requests, each containing at most 100 exact object IDs. Requests ran serially through the shared host throttle at less than one request per second. Exact response bytes, hashes, URLs and capture timestamps remain in `metadata/` and [discovery.json](discovery.json).

The [first selected individual follow-up](../local-chicago-native-images-20261006/README.md) and [further selection](../local-chicago-followup-images-20261006/README.md) check current full object records, independently matched native creators and exact image-resource CC0 declarations before any image download. Discovery leads are not added to the combined reviewed-artwork total.

The [additional sixty-record selection](../local-chicago-next-images-20261006/README.md) adds fifty individually cleared photographs. The [ten-record delivery revisit](../local-chicago-download-recovery-20261006/README.md) resolves earlier HTTP failures through the same exact photographs’ published native download buttons. These operations retain their individual source, visual and database checks; discovery leads still do not constitute image clearance.
