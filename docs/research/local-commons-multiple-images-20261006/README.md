# Multiple Commons image leads — 6 October 2026

Reviewed five previously held artworks with multiple authority-linked Commons files. Two verified public-domain reproductions were saved locally and attached: Edward Okuń's *Portrait of Mrs Herse* and William Pape's *Portrait of Marie de Castellane Radziwiłł*. Their full-frame JPEGs are 93,859 and 93,954 bytes.

Both matches were checked against fresh National Museum in Warsaw records found by exact full inventory. The current objects are `444971` (`MP 191 MNW`) and `1048018` (`M.Ob.2688 MNW`). The old Okuń link, numeric ID `508047`, now identifies an unrelated Utamaro print; Pape's old `502111` returns 404. These legacy links are preserved as source history. The current catalogue and its public-domain image reuse policy support the selected reproductions. Pape's Commons filename uses Elżbieta, whereas the native record and stored title identify Maria/Marie; the filename was not adopted as a sitter correction. Both missing stored inventory fields remain null.

Three other works remain unattached:

- Hudeček's *Psyche*: the originating museum URL failed TLS hostname verification. A separate photographer file also remains held in the [alternate review](../local-commons-photographer-alternate-20261006/README.md).
- Monet's *Fishermen on the Seine near Poissy*: the selected file lacks an unambiguous rendered image licence.
- Tóth's *Beauty, Wealth and Spirit*: three separate panel files were found, without a selected verified reproduction of the complete triptych.

Four negative controls rejected a reused legacy object ID, a different inventory, restricted rights and qualified authorship. The two full compositions were visually reviewed. File hashes, live database links, native rights evidence and stored attribution passed verification; titles, dates, holdings, creator links, identifiers and review status were preserved. HTTP delivery remains incomplete because the existing Next.js server timed out at the latest checkpoint.
