Experiments:
1. Five at a time (recommended): independently append up to five on each click.
   Keep the centre positioned against the first five entries when either grows.
   Show less returns that side to five. Show more includes remaining count.
2. Expand all: independently reveal every remaining entry. Use the same visual
   language, so the long-map cost can be compared directly with experiment 1.
3. Side panel: Show more opens a searchable list for that direction while the
   five-person map stays compact. Initially show at most 20 panel matches and
   reveal another 20 as needed. Evidence opens inside the panel with a back link.

Common behavior:
- Exactly five entries: no Show more. Six entries: show exactly one remaining.
- Count grouped people/source identities, not separate relationship claims.
- Stable saved-research order: documented/consensus evidence first, then name.
  Preserve all types and levels within each entry; grouping does not validate a
  claim or merge artist IDs by display name.
- Draw connectors only to visible nodes. No edge to a Show more control.
- Expand each direction independently; return keyboard focus sensibly.
- Teaching, admiration and artistic influence remain separate claims.
- Unresolved source labels stay labels; do not invent profile links.
- Reduced-motion support, visible focus, 44px targets, no horizontal overflow.

Verification and result

Recommended: Five at a time. The controls show remaining counts and operate
independently; expanded maps retain the initial centre position. Expand all is
available for comparison, with the observed cost of a much taller graph. Side
panel offers search for larger lists while retaining the five-person map.
