# About Artline redesign — 11 October 2026

About is a visual marketing entrance, refined after a
[20-page marketing benchmark](marketing-benchmark-20261011.md). It follows
[Artline's design guidelines](../DESIGN_GUIDELINES.md): Georgia headings,
Avenir controls, shared paper/ink/rust colours and existing navigation icons.

## Visual direction

An open gallery on paper leads into a dark atlas. The headline is substantially
larger; a broad Monet landscape anchors the gallery between Leonardo and
Kandinsky. Each work retains its full composition. Phones lead with the Monet
alone at full width; the other works remain accessible in the guide and timeline
sections. Artist names and dates replace long hero captions.

The timeline is one immersive section with its own heading, action, real dated
paintings and period choices. Museum cards resemble illustrated reading editions,
with city, institution, authentic artwork and the guide's actual artwork count.
They are navigation previews, not facsimiles of the downloadable PDF covers.
Six featured guides occupy one horizontal carousel, showing a few at a time.
Phones show one cover and a preview of the next, with native swipe scrolling.
A larger artist carousel follows, then a short closing invitation.

```text
                See art. Discover its world.

        Leonardo        Monet landscape        Kandinsky
```

## Content and interaction

- The timeline positions six pinned artworks proportionally across 1450–1970,
  using recorded creation dates and preserving ranges. The midpoint locates a
  ranged work, while its full range remains labelled. Alternate rows prevent
  collisions. This is an editorial selection, not a catalogue-density chart.
- Each preview image opens its exact guide passage. “Open interactive timeline”
  passes all six IDs and the date range into the atlas with art, books and events.
- Six pinned guide slugs keep the preview bounded as the directory grows. Only
  those guides' content is opened for the preview; their existing cover images,
  artwork counts and complete compositions are preserved. The carousel shares
  the artist carousel's controls, keyboard navigation and reduced-motion support.
  “Browse all museum guides” opens the complete directory. Guides remain public.
- The artist carousel contains eight curated creators with real artwork images,
  artwork titles and direct public artist links. Previous/next, ArrowLeft/Right,
  Home/End, native touch scrolling and scroll snapping are supported. Controls
  reflect the scroll boundaries and disappear when all content fits. No automatic
  movement; reduced motion is honored.
- Native scrolling and server-rendered cards work without JavaScript. Only the
  scrolling controls need client code. Six existing guide files supply the bounded
  editorial selection; no catalogue API request is added to About.
- Twenty-three image elements reuse fourteen unique existing reproductions;
  twenty-one are displayed in the phone layout. No generated art, new catalogue
  assets, web fonts or dependencies were added.
- Credits are deduplicated by object ID. Rights labels, image-detail links,
  transformation notes and institutional CC BY-SA attributions are preserved.
  Full evidence remains in the guide data. Credits and Pantheon ranking details
  remain in native disclosures with their existing fragment destinations.
- Menus and footer say “About”. Museum collection links preserve sign-in behavior.
- Canonical URL, description, social metadata, AboutPage and breadcrumb structured
  data remain server-rendered. No database writes were made.

## Verification

Browser checks cover metadata and all destinations without JavaScript, exact
artwork navigation, museum sign-in and focus restoration, period filters, timeline
scrolling and selection handoff, artist carousel controls and public artist links.
Responsive checks cover 1440, 1024, 768, 390 and 320px, with WCAG A/AA checks,
image decoding and visual review on desktop and phone. The signed-in sidebar was
also checked at each width, without horizontal page overflow. All eight selected
artist identities were verified through the existing read-only API in the preceding
preview implementation.

ESLint, the production build and all six About browser tests against the production
build pass. The wide layout contains about 280 visible words including captions
and navigation; the remaining detail stays in closed disclosures. Temporary
screenshots and browser outputs live in `/tmp/artline-about-benchmark/`.
The in-app browser connection rejected its session metadata; verification uses
the repository's Playwright installation.
